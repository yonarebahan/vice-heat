VICE HEAT Cover Studio is a static, offline web app that turns your own photos into GTA-style multi-panel cover art: six panel layouts including a pop-out hero, face-aware crops with Smart frame, a striped chrome title with editable caption and cast name tags, six Vice colour grades, and PNG export at 1080x1080, 1080x1350 and 1920x1080. Your photos never leave your machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. To hand the app in as a make.fun entry, run `node main.ts` with MAKEFUN_OUTPUT_DIR set.
